# Proyecto HEMA: Humanoid 1m Robot 🇨🇱

## 🤖 Overview
Development of a 1-meter tall humanoid robot focused on mechanical efficiency and decentralized control. 

## 🛠️ Key Engineering Features
*   **Ankle Actuation:** Pushrod linkage system to minimize unsprung mass.
*   **Structure:** Integration of 3D-printed PETG components with 20mm PVC structural tubing.
*   **Degrees of Freedom:** Ankle joint designed for ±25° (50° total range).

## 📁 Repository Structure
*   `01_Mechanical`: CAD files (.step) and technical drawings (.pdf).
*   `02_Electronics`: Bill of Materials and schematics.
*   `03_Software`: Logic for RPi 4B and MicroPython for RPi Pico.
